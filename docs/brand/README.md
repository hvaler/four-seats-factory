# Brand

| File | Use |
|---|---|
| `logo-light.svg` | Horizontal logo for light backgrounds |
| `logo-dark.svg` | The same logo for dark backgrounds |
| `mark.svg` | The symbol alone, for icons and small sizes |

Four seats seen from above; only one carries the check mark, because only one seat can accept.

The shapes were generated by the operator with an AI image model, from a prompt, after the run.
They were then edited by hand in three ways and no others: the white background was removed, the
colours were set (`#11574C` on light, `#3FA383` on dark, the green of the product UI), and the
white fills inside the letters were turned into real holes so the logo works on any background.
It is not output of the band.
